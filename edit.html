사이트 편집사이트 보기 ↗

칸을 고치면 이 컴퓨터에 자동으로 임시 보관됩니다. 미리보기로 실제 사이트 모양을 확인하고, 저장하기를 누르면 약 1분 뒤 공개 사이트에 반영됩니다. 빈 줄은 저장할 때 지워집니다. 선별 작업마다 사진 칸에서 사진을 올리고, 순서·잘리는 위치·사진 위치를 정할 수 있습니다.

GitHub 연결 (이 컴퓨터에서 처음 한 번)

  1. 토큰 만들기 화면 열기 ↗ (miran-artcode 계정으로 로그인된 상태여야 합니다)
  2. Token name: 영어로 portfolio-edit (한글 이름은 오류가 날 수 있습니다)
  3. Resource owner: miran-artcode, Expiration: 366 days 또는 원하는 날짜
  4. Repository access: Only select repositories → 목록에서 miran-artcode/PORTFOLIO 고르기
  5. Permissions: Add permissions(또는 Repository permissions) → Contents → 오른쪽을 Read and write로. Metadata는 저절로 Read-only가 붙습니다.
  6. 맨 아래 Generate token → 확인 창에서 한 번 더 Generate token → 나온 값(github_pat_…)을 옆의 복사 단추로 복사해 아래 칸에 붙여 넣기. 이 값은 한 번만 보이니 연결 전에 창을 닫지 마세요.

토큰은 이 컴퓨터의 브라우저에만 저장되고 GitHub 말고 다른 곳으로 보내지 않습니다. 이 토큰으로는 PORTFOLIO 저장소의 파일만 고칠 수 있습니다.
